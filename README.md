# MSTC and HPGE Worked Problems

Open the live study site at <https://jjseb.github.io/civil-engineering-worked-problems/>. The home page links directly to each available problem set. Equations are rendered with MathJax, and included diagrams are inline SVG.

Available sets include standalone MSTC and HPGE practice problems and November 2021 and May 2022 exam sets.
