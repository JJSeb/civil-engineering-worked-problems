# CVE 405 Correlation 1 Reviewers

Public GitHub Pages build. Open index.html for the PSAD phone reviewer and correl1.html for the MSTC and HPGE worked-solution set. The latter renders correl1-solutions.md with Marked and MathJax.

The MSTC scan contributes 23 problems and the HPGE scan contributes 40; these are partial sets relative to the 75-question and 50-question exam outlines. Scanned source PDFs and rendered page images are kept locally and excluded from this public repository.
