# CVE 405 Correlation 1 Reviewers

Public GitHub Pages build. Open index.html for the PSAD phone reviewer, correl1.html for the standalone MSTC and HPGE worked-solution set, and ce-ref.html for the five-volume CE REF coverage index. CE REF worked pages currently cover Volume 5 November 2021 HPGE and MSTC, plus May 2022 HPGE and MSTC. Solution pages render Markdown with Marked and MathJax.

The MSTC scan contributes 23 problems and the HPGE scan contributes 40; these are partial sets relative to the 75-question and 50-question exam outlines. Scanned source PDFs and rendered page images are kept locally and excluded from this public repository.
